# TabCat 使用与开发指南

TabCat 基于 WXT、原生 JavaScript 和 CSS 构建，使用 Manifest V3。产品介绍与预览见 [首页](../README.md)。

## 开发与构建

需要 Node.js 22.12+（或更新的受支持版本）和 pnpm。

```sh
pnpm install
pnpm dev          # WXT 启动开发浏览器，输出 output/chrome-mv3-dev，支持热更新
pnpm build        # 输出 output/chrome-mv3
pnpm zip          # 生成可分发的扩展 ZIP
```

## 安装

1. 运行 `pnpm install` 和 `pnpm build`。
2. 打开 `chrome://extensions/`（Edge 使用 `edge://extensions/`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **`output/chrome-mv3`** 目录。
4. 新建标签页，按浏览器提示保留 TabCat 的新标签页设置。
5. 在浏览器扩展菜单中固定 TabCat 图标，方便添加网页。

修改代码后重新构建，并在扩展管理页点击「重新加载」。项目根目录不再是可直接加载的扩展目录。

## 添加当前网页

在普通 HTTP/HTTPS 网页上点击工具栏中的 TabCat 图标：

- 自动填写当前网页的标题与完整网址，可修改后点击「添加到首页」。
- 相同网址不会重复添加；不同路径、查询参数和锚点保留为独立快捷方式。
- 已打开的 TabCat 首页自动刷新快捷方式，无需手动重载。
- 浏览器设置页、新标签页、本地文件等不支持固定，弹窗会说明原因。
- 点击「打开 TabCat 首页」可直接查看结果。

「添加网站」和「添加小组件」共用一个候选侧栏，可切换全部、图标、小组件，支持点击添加或拖到桌面指定位置。侧栏保持打开以便连续添加，桌面自动让出空间；窄屏使用底部候选栏。图标库内置 74 个常用网站和收藏、历史记录、扩展管理、下载内容、浏览器设置共 5 个内置入口。支持分类浏览、按名称/网址/关键词搜索、连续一键添加与跨标签页去重；已添加项目会标记，也可通过「自定义网址」手动添加。新增国内/海外社交、国内/海外 AI 分类，覆盖小红书、X、Instagram、DeepSeek、豆包、ChatGPT、Claude 等。已核验的清晰 favicon、首页 Logo 和品牌备用图随扩展内置，网站库及添加后的首页可离线显示；暂无可靠素材的站点使用名称首字。

默认隐藏所有「＋」。右键桌面空白处可添加网站或进入编辑模式；编辑模式显示「＋」，点击图标可编辑、拖动可排序，点击「完成编辑」或按 Esc 退出。右键图标可编辑、在新标签页打开或移除，移除后可撤销。拖到分页箭头停留可翻页继续排序。设置中的「桌面布局」只保留布局偏好和「编辑桌面」入口，快捷方式直接在桌面管理。点击快捷方式默认在新标签页打开，可在「桌面布局 → 快捷方式打开方式」选择「新标签页」或「当前标签页」，选择会自动保存，独立于搜索的打开方式。

收藏、浏览历史和扩展管理也可删除、撤销；刷新或恢复备份不会自动补回，恢复默认设置会重新提供这些入口。

## 桌面与设置

默认以离线山海壁纸、居中搜索框和彩色圆形图标组成首页，没有分区标题和大时钟。支持窄窗口响应布局。

- **图标外观**：大小（44–128 px）、圆角（0–50%，随图标大小缩放）、不透明度、名称显示、桌面文字颜色、字体和设置面板主题。文字图标支持字号（10–72 px）、字体、字重和颜色；默认根据底色的感知亮度自动选择黑字或白字，也可手动选色。
- **仅新标签页书签栏**：在「桌面布局 → 显示书签栏」开启，读取 Chrome 书签栏的网站和文件夹，支持逐级展开嵌套文件夹（靠边向左展开，窄屏原位进入与返回）、实时同步、横向滚动及书签管理入口。默认关闭，开启后使用磨砂玻璃效果；透明度可调 0–100%，默认 20%。开关和透明度随配置备份保存；书签内容由 Chrome 管理，不复制到 TabCat 备份。开启需扩展的 bookmarks 权限。本栏位于 TabCat 页面内部，只在新标签页显示。
- **桌面布局**：每行 2–12 项、每页 1–6 行、行列间距；桌面自动上下居中并适配窗口高度，首页禁止上下滚动；分页按钮、横向滚轮、触摸滑动和方向键翻页。按住 dock 网格空白区域可用鼠标左右拖动翻页（编辑模式下也支持），拖动不足距离时回弹；鼠标靠近左右边缘显示上一页/下一页按钮，到达首尾页时隐藏不可用方向。
- **桌面编辑**：右上角“编辑桌面”或右键空白处进入编辑模式。拖到想放的格子上稍作停留，其他图标会让出位置；网格紧密排布，小组件换行留下的空格会由后面的图标补上；悬停分页箭头可跨页移动。选中网格项目后按 Alt + 方向键也可排序。旧版本的文件夹会自动展开回原位置；移除快捷方式或组件后可撤销。设置页仅保留布局偏好。
- **小组件**：右上角“添加小组件”打开统一候选栏并显示样式预览卡片，点击即按默认配置添加，也可拖入桌面；添加后进入编辑模式设置标题、尺寸和专属选项。网页组件需填写 HTTPS 地址后添加，倒数日默认目标为当天。可添加备忘、天气、HTTPS 网页、时钟、日历、待办、倒数日、番茄钟和计算器，默认追加到桌面末尾，与快捷方式共享网格。支持 2×2、3×2、4×3 尺寸，窄屏自动收窄，较高组件自动增加网格行数。点击组件空白处会弹出详情，右键组件可打开、设置或移除；备忘可保存多条，打开后左侧是列表、右侧编辑，桌面卡片显示最近编辑的一条，逐次输入自动保存；天气默认通过 ipwho.is 按当前网络 IP 定位城市，也可手动输入城市，从下拉列表中用鼠标或方向键选择；同名结果优先主要城市，并显示省份和所属地区。旧组件保留手动城市，可在设置中切换为自动定位。IP 定位及 Open-Meteo 天气数据在页面内缓存 15 分钟，刷新按钮会重新定位并更新天气；定位失败可重试或手动选城。代理或 VPN 可能影响定位结果，不保存原始 IP。网页以 sandbox iframe 加载，不保证第三方网站允许嵌入；保留“独立打开”入口，不绕过网站限制。
- **离线工具**：时钟可选择时区和 12/24 小时制；日历支持翻月、返回今天；待办支持添加、勾选、删除、清理已完成和撤销（每组件最多 100 项）；倒数日按本地日期显示剩余天数、当天或已过去天数。番茄钟可设置 1–120 分钟专注与 1–60 分钟休息，支持开始/暂停/重置，按结束时间在刷新后恢复，完成时仅在组件内提示；不自动进入下一轮。计算器支持加减乘除、括号和百分比（`50% = 0.5`），输入与结果仅保留在当前页面，不写入备份。六种工具不产生外部网络请求。
- **搜索设置**：显示开关、宽高、圆角、不透明度、链接打开方式；Google / Bing / 百度、添加搜索引擎（`%s` 代表关键词）、默认引擎与拖动排序。三个默认引擎的图标已内置，联想使用所选引擎接口，支持 ↑ ↓ / Enter / Esc 和中文输入法，可在设置中关闭。自定义引擎仍可搜索，但不会调用不匹配的联想接口。按 `/` 聚焦搜索框。
- **壁纸背景**：Bing 每日壁纸、Bing 最近几日图库、Picsum 横向摄影图库（每天 / 每小时 / 每次新标签页 / 手动轮换、最近一张离线缓存；每天 / 每小时轮换由扩展后台定时更新，隐藏页面同步已加载的图片，回到前台不触发换图）、原创离线壁纸、本地 JPG / PNG / WebP 上传（10 MB 以内）、在线图片地址、模糊（0–40 px）、白色磨砂（0–60%）与黑色磨砂 / 压暗（0–70%），三种效果默认均为 0；右下角换一张照片（内置、本地或自定义壁纸会切换到 Picsum，Bing 今日会切换到 Bing 图库）。
- **时间日期**：时钟默认隐藏，可开启；支持时区、12/24 小时制、日期样式、农历、字号和字重。
- **浏览器同步**：在「数据」页按设备开启，通过 `chrome.storage.sync` 在登录同一浏览器账号的设备间同步网站、小组件（含备忘、待办）、搜索引擎和设置。配置压缩后分块保存，受浏览器约 100 KB 的同步空间限制，超出时提示精简。上传的图标不进入浏览器同步，只以内容引用 `tabcat-icon:<sha256>.<ext>` 代替。本地上传的壁纸不同步，正在使用本地壁纸的设备也不会被其他设备的壁纸选择覆盖。开启时先显示浏览器同步里已有的配置（网站和小组件数量、更新时间），再选择「合并」「用云端覆盖本机」或「用本机覆盖云端」：合并保留两边的网站和小组件、相同网址只留一个，其他设备改过的设置以云端为准；云端还没有配置时会提示可能尚未下载完，确认后才上传本机配置。之后每次同步都记下所基于的版本，按共同版本三方合并：两台设备同时改动不同内容时互不覆盖，新设备第一次上传的默认值也不会重置其他设备的设置。
- **图片同步（WebDAV）**：在「数据」页填写 WebDAV 地址、用户名和密码（建议用网盘的应用密码），账号只保存在本机 `chrome.storage.local`。连接时会检查账号并创建 `TabCat/icons/` 文件夹。上传的图标按内容哈希命名为 `<sha256>.<ext>` 存入其中，同一张图片总是同一个文件名，设备之间不会互相覆盖。其他设备通过浏览器同步拿到引用后，从 WebDAV 下载并校验哈希，再换回本机图片；还没上传到 WebDAV 的图片先显示网站图标，每 30 分钟重试。删除快捷方式不会删除 WebDAV 上的文件。
- **备份恢复**：导出 / 导入 TabCat JSON，包含网站、小组件（含备忘内容）、设置和本地壁纸；兼容导入 Infinity v2 `.infinity` 和 iTab JSON。先展示数量、跳过项和文件夹展开提示，再确认；外部备份追加去重，Infinity 仅导入图标外观设置（大小、圆角、不透明度、名称显示），iTab 覆盖可映射设置；TabCat 备份完整恢复。
- **单个网站**：编辑窗口可直接切换网站图标、单字图标和自定义图片。输入网址自动获取网站图标；单字图标默认使用名称首字，支持自定义汉字、字母或 emoji。可编辑名称、网址、图标底色、图标图片（填写网址，由扩展下载并缓存在本机，同步只带网址；也可以上传本地图片，保存在本机，连接 WebDAV 后同步到其他设备）、内部图片大小（40–160%）、铺满裁切或完整显示，以及大小、百分比圆角、名称字号。文字图标可单独覆盖全局的字号、字体、字重和颜色，留空则跟随全局。

界面操作和浏览器内置入口采用 [Iconify Lucide](https://icon-sets.iconify.design/lucide/) 图标，按需打包，离线可用。搜索引擎图标来自对应网站并内置到 `public/search/`。

网站快捷方式优先使用清晰的 favicon、Apple Touch Icon 或 manifest 图标，按图片实际解码尺寸检查，16–48 px 小图改用首页页眉、导航区的 Logo，支持 srcset、内联 SVG 和 CSS 背景图。普通尺寸保留 64 px 及以上图标，放大图标或更高像素密度会提高门槛；SVG 不受栅格尺寸限制。少数派、京东等已核验的清晰 favicon 随扩展内置，微博使用官网彩色 SVG。无可用图片时使用品牌备用图或文字。横向 Logo 完整显示。工具栏添加读取已渲染页面，手动添加读取静态 HTML；缺少品牌图时尝试首页。内联 SVG 清理后转换为最高 512 px PNG，后台请求不携带登录凭据。「重新获取」跳过旧结果，手动图片和文字优先。

网站库内置图标不产生外部图片请求；手动添加/编辑的自动发现、自定义图标和在线壁纸会连接对应网站及其图片域名。搜索联想把输入内容发送给当前选择的搜索引擎；关闭后不再发送。在线壁纸缓存与自动图标缓存独立保存，不包含在配置备份中。Lucide 许可随扩展保存在 `lucide-LICENSE.md`。外部备份的格式依据和限制见 [导入格式说明](import-formats.md)。

所有配置保存在本机 `chrome.storage.local`；开启浏览器同步后，再把除本地壁纸和上传图标外的配置副本写入 `chrome.storage.sync`；连接 WebDAV 后，上传的图标写入 WebDAV。计时状态、天气缓存和图标缓存只保存在本机，尚未实现系统通知。外部备份中的文件夹会展开为平面快捷方式，未支持的组件会在导入预览中说明。

参考分析见 [Infinity 功能对照](infinity-reference.md)，原创壁纸信息见 [壁纸来源](wallpaper-source.md)。

图标圆角采用 CSS 百分比：0% 为直角，50% 为圆形。例如 25% 圆角在 80 px 图标上为 20 px，在 120 px 图标上为 30 px。旧配置和旧 TabCat 备份的像素圆角会自动换算为百分比，重复加载不会再次换算。字体设置仅作用于文字图标，不改变图片中的字样或图标下方的名称。

## 历史配置兼容

配置迁移会保留网站、搜索引擎和自定义外观值。保留原来的 `tabcat` 存储键与配置字段；扩展 ID 不变时可直接读取旧配置。

`wxt.config.ts` 在 manifest 中写入 Chrome 应用商店分配的公钥 `key`，扩展 ID 固定为 `hgblemcigdpgbhdmkhfoeicmpnhkmngg`，无论从哪个目录加载都与商店版本相同。加入固定 key 之前安装的版本 ID 随加载目录变化，与新版本互不共享数据：请先在旧扩展中导出备份，加载新版本后导入，确认无误再移除旧扩展。

## 权限

- `favicon`：读取浏览器缓存中的网站图标。
- `storage`：保存网站和设置。
- `activeTab`：用户点击扩展时读取当前标签页标题、网址和页面 Logo。
- `scripting`：仅在点击工具栏添加网页时读取当前网页的图标声明。
- `bookmarks`：开启「显示书签栏」时读取并展示浏览器书签，不修改书签。
- `alarms`：定时轮换壁纸、浏览器同步和 WebDAV 图片同步重试。
- `http://*/*`、`https://*/*`：读取快捷方式对应网页、manifest 与高清图标，以及 Bing 壁纸和搜索建议接口；不常驻注入网页脚本。

更新扩展后需要重新加载，使新增权限生效。

## 验证

```sh
pnpm test                 # URL 校验、旧数据兼容、重复添加、并发合并
pnpm build
```

界面改动请构建后在浏览器中加载 `output/chrome-mv3` 手动验证。

推送到 `main` 或提交 PR 时，GitHub Actions 会运行测试并打包，ZIP 可在该次运行的 Artifacts 中下载。

## 发布

```sh
pnpm release              # 补丁版本 +1；也可传 minor、major 或具体版本号，加 --dry-run 只检查不推送
```

脚本在 `main` 上确认工作区干净且不落后远端，跑测试和打包，然后更新 `package.json` 版本、提交、打 `vX.Y.Z` 标签并推送。标签触发 `.github/workflows/release.yml`：打包后创建 GitHub Release 并附上 ZIP，同时用 Chrome 应用商店 API v2 上传并提交审核。

商店凭据保存在仓库的 Actions secrets 中，首次配置或更换时在本地设置环境变量后运行 `pnpm release:secrets`，它会先用 dry run 校验凭据，再写入 GitHub：

| 环境变量 | 来源 |
| --- | --- |
| `CHROME_PUBLISHER_ID` | 开发者信息中心 → 账号 → 发布者 ID |
| `CHROME_SERVICE_ACCOUNT_KEY_FILE` | 服务账号 JSON 密钥文件路径（或改设下面两项） |
| `CHROME_SERVICE_ACCOUNT_CLIENT_EMAIL` | JSON 密钥中的 `client_email` |
| `CHROME_SERVICE_ACCOUNT_PRIVATE_KEY` | JSON 密钥中的 `private_key` |

## 目录

```text
entrypoints/newtab/    新标签页：main.js 负责启动与全局快捷键，app.js 保存共享状态与存储，
                      其余模块按功能拆分（desktop-view 桌面与分页、sites 网站编辑、
                      engines 搜索引擎、settings 设置面板、wallpaper 壁纸、backup 备份、sync 同步开关、
                      context-menu 右键菜单、clock 时钟）
entrypoints/popup/     添加当前网页的弹窗
entrypoints/background.js  统一串行处理配置写入、浏览器同步与 WebDAV 图片同步
lib/                  默认配置、数据校验和存储通信
tests/                单元测试
public/icon/          扩展图标
wxt.config.ts         WXT / Manifest 配置
```

参考：[WXT 入口约定](https://wxt.dev/guide/essentials/entrypoints)、[Infinity 功能介绍](https://www.infinitytab.com/)。

下拉框的字段和展开列表统一使用设置面板样式，支持深色、键盘选择和滚动；使用 Chrome 135+ 的可定制 select（https://developer.chrome.com/blog/a-customizable-select），旧版浏览器回退到标准选择器。修改默认值不会覆盖已经保存的背景效果设置。
