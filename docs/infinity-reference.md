# Infinity 参考与本次调整

参考用户提供的 `infinity-new-tab-pro@latest.zip`，内含 Infinity New Tab Pro 11.0.41 的 CRX。读取了 Manifest、新标签页的布局样式、默认配置和中文设置文案，并在断网的独立临时 Chromium 配置中核对页面。参考扩展未安装到日常浏览器。

## 从实际插件确认的设计

- 全屏壁纸为底，默认没有大时钟、顶部品牌导航或内容分区标题。
- 搜索框居中且轻量，默认隐藏强调色搜索按钮；快捷方式以圆形图标排列。
- 图标数量、行列间距、大小、圆角、不透明度和文字显示均可调整。
- 搜索框可调整大小、圆角、不透明度，也可隐藏。
- 使用侧栏设置、桌面右键菜单、图标拖动排序和分页。
- 包含本地壁纸、在线壁纸源、备份恢复，以及文件夹、天气、待办和笔记等工具。

## TabCat 1.2 实现范围

重做全屏壁纸、搜索框、彩色圆形图标、分页与边角工具；默认隐藏时钟，可在设置中开启。新增首页拖动排序、右键菜单、删除后撤销、跨页拖动翻页、键盘翻页与 `/` 聚焦搜索。

设置侧栏分成图标外观、桌面布局、搜索设置、壁纸背景、时间日期、备份恢复。支持图标与搜索框尺寸、圆角、不透明度、间距、内容位置、本地和 Bing 每日壁纸、模糊、磨砂浓度与压暗。默认隐藏添加按钮，右键空白处进入编辑模式后显示添加入口并允许拖动排序。支持 TabCat JSON 导入导出，以及 Infinity v2 / iTab 备份兼容导入，先预览再确认。界面图标使用按需打包的 Iconify Lucide；网站优先使用实际分辨率达标的 favicon，模糊小图改用首页品牌 Logo（支持 SVG），无法获取时使用品牌备用图或文字占位。搜索引擎图标已内置，Google / Bing / 百度支持对应接口的搜索联想。

保留 WXT、添加当前网页、去重、实时同步、搜索引擎管理、时区和农历，以及原有快捷方式数据。原先未调整的默认外观会升级；自定义壁纸、尺寸等保留。默认壁纸为原创生成，提示词见 `wallpaper-source.md`。

天气、待办、笔记、文件夹、账号云同步和在线壁纸服务未在本次实现，不将其展示成可用入口。备份格式为 TabCat 格式，不承诺兼容 Infinity 备份。

## 设置组件与网页 Logo

参考包默认站点以 `bgType: image` 和完整 `bgImage` 品牌图片呈现。TabCat 采用整张图片填充图标的方式，并独立加入缩放与完整显示选项。未复制参考包的图标 CDN 素材；常用品牌备用图形通过 Iconify Simple Icons 按需内置。设置使用浮层、分组卡片和统一表单组件。
