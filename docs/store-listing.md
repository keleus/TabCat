# 插件说明

TabCat 在 Chrome 网上应用店、Edge 加载项等商店上架时使用的文案和素材，按 Chrome 开发者后台的填写顺序整理。功能变化后请同步更新本文与 `package.json` 的 `description`。

## 上传软件包

1. 在 `package.json` 中提高 `version`（每次上传都必须比商店里的版本号大）。
2. 运行 `npm test` 和 `npm run zip`。
3. 在开发者后台上传 `output/tabcat-<版本>-chrome.zip`。

## 名称

TabCat 新标签页（取自 manifest 的 `name`，上限 75 字符）

## 简短说明

商店摘要和 manifest 的 `description` 共用这一句（由 `package.json` 生成，Chrome 限 132 字符以内）：

> 按自己习惯布置的新标签页：常用网站、待办天气等小组件和每日壁纸，本地保存，可用浏览器同步与 WebDAV 跨设备使用。

## 权限理由

| 权限 | 理由 |
| --- | --- |
| `storage` | 在本机保存网站、桌面布局、小组件内容和设置；用户开启浏览器同步后写入 `storage.sync`。 |
| `activeTab` | 用户点击工具栏按钮时，读取当前标签页的标题和网址，添加到首页。 |
| `scripting` | 用户点击工具栏按钮后，在当前标签页读取一次网页声明的图标和 Logo，用作快捷方式图标；不常驻注入脚本。 |
| `favicon` | 读取浏览器已缓存的网站图标，作为快捷方式图标的备用来源。 |
| `bookmarks` | 用户开启「显示书签栏」时，在新标签页中只读展示浏览器书签，不修改书签。 |
| `alarms` | 定时轮换壁纸，以及浏览器同步和 WebDAV 图片同步失败后的重试。 |
| 主机权限 `http://*/*`、`https://*/*` | 快捷方式可以是任意网站，需要读取对应网页和图标文件来生成清晰图标；也用于 Bing 壁纸、搜索建议、天气接口和用户填写的 WebDAV 服务器。后台请求不携带浏览器 Cookie。 |

## 远程代码

选择「否，我没有使用远程代码」。所有脚本随扩展打包；网页组件在 sandbox iframe 中加载第三方页面，不获得扩展 API，不算扩展的远程代码。

## 数据使用

TabCat 没有自己的服务器，开发者不收集、不出售任何用户数据。以下请求只在用户使用对应功能时发生，直接发往第三方服务：

- **搜索建议**：输入内容发送给所选搜索引擎（Google、Bing 或百度），可在设置中关闭。
- **天气**：自动定位时，ipwho.is 根据网络 IP 返回城市；城市名称和坐标发送给 Open-Meteo。不保存 IP 地址。
- **在线壁纸**：从 Bing 或 Picsum 加载图片。
- **网站图标**：访问快捷方式对应的网站及其图片域名。
- **WebDAV**：上传的图标保存到用户自己填写的 WebDAV 服务器，账号只保存在本机。
- **浏览器同步**：通过浏览器账号自带的同步服务传输配置，不经过 TabCat。

填写商店隐私问卷时，数据类型都不勾选，三项承诺全部勾选，不填写隐私权政策网址。TabCat 不把数据发给开发者；上面这些请求由用户主动使用的功能直接发往第三方服务。如果审核认为天气自动定位（向 ipwho.is 发送 IP）属于收集位置信息，再勾选「位置」并补充隐私权政策。

详细的接口地址和缓存规则见 [网络资源说明](network-sources.md)。

## 图片素材

运行 `npm run store-assets` 从猫猫 SVG、内置壁纸和 [desktop.webp](store/source/desktop.webp) 生成到 `docs/store/`。截图和宣传图导出为 JPEG，因为商店不接受带透明通道的 PNG。

| 素材 | 商店要求 | 文件 |
| --- | --- | --- |
| 商店图标（必填） | 128×128 PNG；图案 96×96，四周各留 16 px 透明边距 | [icon-128.png](store/icon-128.png) |
| 屏幕截图（至少 1 张，最多 5 张） | 1280×800 或 640×400，JPEG 或不带透明通道的 PNG，直角、无留白 | [screenshot-1-desktop.jpg](store/screenshot-1-desktop.jpg) |
| 小型宣传图块（必填） | 440×280，JPEG 或不带透明通道的 PNG | [promo-small-440x280.jpg](store/promo-small-440x280.jpg) |
| 顶部宣传图块（选填） | 1400×560，JPEG 或不带透明通道的 PNG | [promo-marquee-1400x560.jpg](store/promo-marquee-1400x560.jpg) |
| 宣传视频（选填） | YouTube 链接 | 暂无 |

原始截图是 2000×1140 的桌面全貌，脚本裁成 16:10 后缩放到 1280×800，并把右上角工具按钮和右下角壁纸名称移回新的右边缘。

`docs/previews/` 里的预览图是旧版界面，不要用于上架。建议再补 2–4 张当前版本的截图，放进 `docs/store/`，命名为 `screenshot-2-*.jpg` 等：

1. 小组件：备忘、待办、天气和时钟摆在桌面上
2. 编辑桌面：拖动排序
3. 设置面板：壁纸背景或图标外观
4. 添加网站：候选侧栏的图标库

截取方法：在 Chrome 打开 TabCat 新标签页，按 F12 打开开发者工具，切换设备工具栏（Ctrl/⌘ + Shift + M），尺寸填 1280 × 800、缩放 100%，再从「⋮ → 截取屏幕截图」保存。
